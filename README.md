# 💊 RMP資材クイックファインダー (PMDA Direct Access Tool)

薬局・医療機関の調剤室や投薬カウンターで、医薬品リスク管理計画（RMP）に基づく「患者向け資材」「適正使用ガイド」などのRMP資材へ迅速にアクセスするための検索・直結ツールセットです。

PMDA（医薬品医療機器総合機構）の「RMP提出品目一覧」からデータを抽出し、医薬品名や一般名で即座に絞り込んで、**目的の品目のPMDA資材詳細ページへ1クリックで直結**します。

---

## 📂 ファイル構成

| ファイル名 | 役割 |
| :--- | :--- |
| **`rmp_html.js`** | **ブックマークレット用コード**。<br>PMDAのWebページ（動的DOM）からレンダリング済みHTMLを一発ダウンロードします。 |
| **`build_rmp_data.py`** | **データ抽出スクリプト**。<br>ダウンロードされたHTMLから品目名、一般名、製造販売業者名、YJコード（7桁）、詳細URLを抽出して `rmp_data.json` を作成します。 |
| **`create_viewer.py`** | **ビューワー生成スクリプト**。<br>`rmp_data.json` のデータを埋め込み、単体で動く `index.html` を生成します。 |
| **`rmp_data.json`** | 抽出された医薬品マスターデータ（JSON形式）。 |
| **`index.html`** | **完成した検索ツール本体**。<br>ブラウザで開くだけで検索・資材ページアクセスが可能です。 |

---

## 🛠️ 事前準備

### 1. Python環境の準備
本ツールはデータ抽出・生成にPythonを使用します。
```bash
pip install beautifulsoup4
```

### 2. ブックマークレットの登録（初回のみ）
ブラウザ（Chrome / Edge 等）に、PMDAの画面からHTMLを抽出するためのブックマークレットを登録します。

1. ブラウザのブックマークバーで右クリックし、「**ページを追加**」を選択します。
2. 名前を「**RMP HTML取得**」などに設定します。
3. URL欄に以下のコード（`rmp_html.js` の内容）をそのまま貼り付けて保存します。

```javascript
javascript:(function(){const html='<!DOCTYPE html>\n'+document.documentElement.outerHTML;const blob=new Blob([html],{type:'text/html;charset=utf-8'});const a=document.createElement('a');a.href=URL.createObjectURL(blob);a.download='rmp_rendered.html';document.body.appendChild(a);a.click();document.body.removeChild(a);})();
```

## 🚀 使い方（初回のツール作成手順）

ツールの作成・利用は以下の **4つのステップ** で行います。

```
[PMDAサイト]
     │
     ▼ (ブックマークレット実行)
[rmp_rendered.html]
     │
     ▼ (python build_rmp_data.py)
[rmp_data.json]
     │
     ▼ (python create_viewer.py)
[index.html] を開いて検索！
```

### ステップ 1: PMDAサイトからHTMLを抜き出す
1. ブラウザで PMDAの [RMP提出品目一覧ページ](https://www.pmda.go.jp/safety/info-services/drugs/items-information/rmp/0001.html) を開きます。
2. 医薬品リストの表が画面に表示されたら、事前準備で登録したブックマークレット（**RMP HTML取得**）をクリックします。
3. `rmp_rendered.html` がブラウザの「ダウンロード」フォルダに保存されます。

### ステップ 2: PythonでJSONを作る
ターミナル（PowerShell / コマンドプロンプト）でこのツールのフォルダを開き、以下を実行します。

```bash
python build_rmp_data.py
```
* ※ダウンロードフォルダ内の `rmp_rendered.html` を自動検出して作業フォルダに移動し、全品目のデータを解析して `rmp_data.json` を出力します。

### ステップ 3: それをもとに index.html を作成する
続けて以下を実行します。

```bash
python create_viewer.py
```
* ※`rmp_data.json` のデータを埋め込んだスタンドアロンのWebビューワー `index.html` が生成されます。

### ステップ 4: index.html を開いて使う
1. 生成された **`index.html`** をダブルクリックしてブラウザで開きます。
2. 検索窓に医薬品名や一般名を入力します（例: `フォシーガ`、`ダパグリフロジン`、`アイクルシグ`）。
3. 表示されたカードの「**📄 PMDA資材ページを開く**」をクリックすると、別タブでPMDAの資材一覧（患者向け資材や適正使用ガイド）が直接開きます！

## 🔄 データの更新手順（新薬追加時・定期メンテナンス）

新薬が承認された際や、月1回などの定期更新を行うときは、以下の手順ですぐに最新化できます。

1. **PMDAサイトで最新HTMLを取得**
   - [RMP提出品目一覧ページ](https://www.pmda.go.jp/safety/info-services/drugs/items-information/rmp/0001.html) を開き、ブックマークレットをクリック。
2. **スクリプトを実行して再生成**
   - ターミナルで以下のコマンドを実行します（2つまとめて実行可能です）：
     ```bash
     python build_rmp_data.py && python create_viewer.py
     ```
3. **完了**
   - これだけで `index.html` に最新の医薬品データが反映されます。

## 💡 薬局・現場での運用ヒント

- **共有PCのデスクトップにショートカットを配置**
  - 作成した `index.html` のショートカットを調剤室の共有PCデスクトップに置き、アイコンや名前を分かりやすく（例: 「💊RMP資材検索」）しておくと、スタッフ全員がすぐに活用できます。
- **よく出る資材のローカル保存**
  - 頻繁に処方される医薬品（抗がん剤、SGLT2阻害薬、新規抗凝固薬等）の資材PDFは、あらかじめダウンロードして共有フォルダに保管しておくと、急なネット回線の不調時にもスムーズに対応できます。
